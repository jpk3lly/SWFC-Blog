Semantic HTML

This is part of the Codecademy HTML & CSS projects. Creating your own cheatsheet on what you've learned so far.

Semantic HTML tags clearly describe the meaning and purpose of the content.

The benefits of using Semantic HTML are as follows:

  • Accessibility - Screen readers understand your content better
  • SEO - Search engines can index your content properly.
  • Maintainability - Other developers (and future you) understand the structure.
  • Styling - Easier to target with CSS.

Document Structure

The HTML tags below are used to provide document structure:

Header

Top section of a page or section, usually contains logo, nav, heading

Nav

Navigation links (menu, table of contents)

Main

Main content of the page (only one per page)

Section

Generic section of content, usually with a heading

Article

Self-contained content (blog post, news article, comment)

Aside

Sidebar content, related but separate from main content

Footer

Bottom section, usually contains copyright, links, contact info

Content Organisation

h1 to h6

Headings (h1 is most important, h6 is least)

p

Paragraph of text

figure

Self-contained content like images, diagrams, code snippets

figcaption

Caption for a figure element

blockquote

Block of quoted text from another source

cite

Reference to a creative work (book, song, article title)

Lists

ul

- Unordered list (bullet points)

ol

- Ordered list (numbered)

li

- List item (goes inside ul or ol)

dl

- Description list

dt

- Term in a description list

dd

- Description of the term

Text Meaning

strong

Important text (usually bold)

em

Emphasized text (usually italic)

mark

Highlighted/marked text

time

Dates and times

abbr

Abbreviation or acronym

code

Inline code snippet

pre

Preformatted text (preserves spaces and line breaks)

Interactive

details

Expandable/collapsible content

summary

Heading for details element (clickable)

dialog

Dialog box or modal

Forms (Semantic Structure)

form

Form container

fieldset

Groups related form elements

legend

Caption for a fieldset

label

Label for a form input

Other Useful Tags

address

Contact information

hr

Thematic break (horizontal rule)

br

Line break
